How to record a run:

1. Reset the environment with `scripts/reset_environment.sh`.
2. Confirm the starting verifier fails: `scripts/verify_starting_state.sh`.
3. Point the coding agent only at `environment/repo` plus `task/instruction.md`.
4. Do not paste `solution/reference_notes.md` or the patch into the agent context.
5. After the agent stops, run the full verifier from the repo root.
6. Write what the agent actually did. If something is unknown, leave it as `Unknown`.
